# CINEVA — Streaming UI

Responsive streaming-platform frontend built with React and Vite.

## Run locally
1. Install Node.js 20 LTS or newer.
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.

## Production build
Run `npm run build`. Vite outputs the site to `dist/`.

## Vercel settings
- Framework: Vite
- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`
- Root directory: `./`

This is an independent frontend demo, not an official Netflix product. It does not include licensed video playback or real user accounts.
